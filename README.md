# Closest Pair Visualizer

Step-by-step visualizer for the divide and conquer closest 
pair algorithm built with Python and Streamlit.

## Tech Stack
Python · Streamlit · Matplotlib · NumPy

## Features
- Visualizes brute force and divide and conquer approaches
- Step-by-step animation of the algorithm
- Supports custom and random point inputs

## Run locally
pip install -r requirements.txt
streamlit run app.py
